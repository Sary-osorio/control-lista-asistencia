> ## 📝 Instalación del Sistema de Control de Asistencias
> 
> ### Requisitos previos 
> Node 22.20.0
> ### 🔧 Paso 1: Configurar `.env`
> Ajusta tus parámetros de base de datos y entorno.
>
> ---
> ### 📦 Paso 2: Instalar dependencias
> ```bash
> composer install
> ```
>
> ---
> ### 🗄 Paso 3: Ejecutar migraciones
> ```bash
> php artisan migrate
> ```
> ### 🗄 Paso 4: General la llave del proyecto 
> ```bash
> php artisan key:generate
> ```
> ### 🗄 Paso 6: Instalar los node_modules
> ```bash
> npm installl
> ```
> ### 🗄 Paso 5: Correr el proyecto
> ```bash
> php artisan migrate
> ```
